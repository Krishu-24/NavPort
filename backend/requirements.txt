# 4.0.1 fixed CVE-2024-6221, where Access-Control-Allow-Private-Network was

# 22.0.0 fixed CVE-2024-1135, request smuggling via conflicting Transfer-
# Encoding headers, which matters because gunicorn is what serves production.
gunicorn==23.0.0
